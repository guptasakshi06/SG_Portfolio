## Startup maintenance follow-up — 2026-11-03

This follow-up supersedes the temporary-runtime setup and stopped-preview notes above. Original S01 checks remain historical evidence.

Reproduced the owner’s startup failure by running ordinary `npm run dev -- --host 127.0.0.1` in the default Node 18.19.1 shell. Vite/Rolldown exited 1 because Node 18 does not export `styleText` from `node:util`. The original `/tmp/sg-portfolio-toolchain` directory was gone.

Added exact development dependency `node@24.22.2`; npm scripts resolve its local binary. An initial check passed, but a subsequent plain `npm ci` under Node 18 skipped optional native bindings and the next lint failed to load the Oxlint native binding. This exposed an install-time runtime requirement, so merely pinning the binary was insufficient.

Added `npm run setup` → `npm exec --yes --package=node@24.22.2 -- node scripts/install.mjs`. The small installer invokes npm ci with the modern executable and its bin directory on the child process PATH. This uses only built-in Node modules and propagates the install exit status. No machine-global runtime changes, temporary toolchain paths or application changes.
